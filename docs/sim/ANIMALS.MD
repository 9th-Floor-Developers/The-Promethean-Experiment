they have status values 

HP - health bar of the animal it dies if this reaches 0, regenerate when stamina is 90% full
stamina - can be regenerated slowly, influences speed
nutrition - animal takes damage when this is 0, regenerated by eating, nutrition is reduced randomly when stamina is reduced
hydration - animal takes damage when this is 0, regenerated by drinking, hydration is reduced randomly when stamina is reduced
age - (in days) starts as 0 as animal age increases their stamina regeneration decreases

every animal is an Action which it is currently doing, these change based on the situation 
including
RUN_FROM_PREDATOR - runs away from a predator
ATTACK_TARGET <target> - attacks the target if it is an animal it deals 
DRINK_WATER <target position>
EAT_FOOD <target object>
REPRODUCE_WITH <target animal> 

animals with HARD CODED AI trait will be driven by 'feeling'
these a numerical values decide what action the animal wants to do

there is
'fear' which makes the animal run away from the nearest preditor animal
'hunger' which makes the animal find food
'thirst' which makes the animal find water
'libido' which makes the animal want to reproduce
