they have status values 

HP - health bar of the animal it dies if this reaches 0, regenerate when stamina is 90% full
stamina - can be regenerated slowly, influences speed
nutrition - animal takes damage when this is 0, regenerated by eating, nutrition is reduced randomly when stamina is reduced
hydration - animal takes damage when this is 0, regenerated by drinking, hydration is reduced randomly when stamina is reduced
age - (in days) starts as 0 as animal age increases their stamina regeneration decreases

every animal is an Action which it is currently doing, these change based on the situation 
including
REST - do nothing
WANDER - move randomly 
EXPLORE - move far from the original possible location
RUN_FROM_PREDATOR - runs away from a predator
ATTACK_TARGET <target> - attacks the target if it is an animal it deals 
DRINK_WATER <target position>
EAT_FOOD <target object>
REPRODUCE_WITH <target animal> 

animals with HARD CODED AI trait will be driven by 'feeling'
these a numerical values decide what action the animal wants to do

there is
'fear' which makes the animal run away from the nearest preditor animal
'hunger' which makes the animal find food
'thirst' which makes the animal find water
'libido' which makes the animal want to reproduce

animals with SOFT CODED AI trait will 'feelings'  drive the action like the HARD CODED AI
but the 'feelings' will be the output in of a neural network

so the neural network will
world environment inputs → hidden layers → 'feelings'

this will use a version of Q learning where actions get rewarded and recorded per animal
and every time the animal rest it uses that data to train the neural network

the size of each hidden layers and the amount of hidden layers are inherited from their parents plus some modification

SOFT CODED AI - details

the network outputs one value ('feeling') per drive: FLEE, EAT, DRINK, MATE, REST, EXPLORE
the strongest drive wins (10% of the time a random drive is tried instead, so the animal keeps exploring new behaviour)
the drive is turned into an action by the same target search as the HARD CODED AI (nearest food, water, mate, predator)
fear/hunger/thirst/libido shown for a SOFT CODED animal are the softmax shares of FLEE/EAT/DRINK/MATE

inputs (all roughly 0..1): hp, nutrition, hydration, stamina, age (vs elderly age), readiness to breed,
closeness of the nearest predator, food, water and mate, time of day (sin, cos), whether its activity cycle says it should be awake,
how much toxin (venom or poison) is in its body (so it can learn to leave VENOMOUS and POISONOUS species alone),
and how loudly it hears the animal that matters most to it (HEARING only, 0 without the trait): the nearest danger it heard if it is prey,
the nearest animal it heard if it is a hunter - loudness only, never direction, like the closeness inputs

a decision is made when the action cooldown ends, the current action becomes impossible, or a predator comes into view
wellbeing of a need = 1 - (1 - fraction full)^2, so the same gain counts more when the animal is low (drinking while parched)
reward = 10 x (change in nutrition wellbeing + change in hydration wellbeing + 2 x change in HP as a fraction of max, +1 for each offspring)
each decision is remembered with the reward collected until the next decision (up to 200 own decisions per animal)
learning from others: when an animal finishes a decision, every same-species SOFT CODED animal that can see it (within its own view range)
remembers that decision too, in a separate memory of observed decisions (up to 100); every animal still has its own unique data,
since what it saw depends on where it was
every tick an animal is in REST it replays 16 remembered decisions through Q-learning (learning rate 0.05, discount 0.9), 30% of them from observed decisions

children inherit the hidden layer shape (from a random parent, sizes averaged where both parents have the layer)
and weights that are only 25% the parents' average and 75% fresh random (so behaviour is mainly learned, not passed on), both with mutation: +/- 2 neurons per layer (30% chance), add or remove a layer (5% each, 1 to 4 layers, 2 to 64 neurons)
founders start with one hidden layer of 2 neurons and random weights
every hidden neuron costs stamina each tick, so a bigger brain has to earn its keep
'intelligence' (shown in the inspector) = the number of hidden neurons; the inspector also draws the network
the statistics page shows thirst & hunger deaths per 100 animal-days per species, which measures how well each animal copes regardless of population size

tested (JVM, 10-15 in-game days): with learning on, brains become need-dependent (given the same situation, about 65-70% pick DRINK when thirsty vs ~35-40% when not,
~75% pick EAT when hungry vs ~35-40% when not); with learning switched off nothing changes and the species dies out
with brains mostly learned, learning from others matters a lot: Learning lab preset (seed 42) day 15 has 136 learners with it, 22 without
known weakness: fleeing is not learned yet (animals caught by predators rarely survive to rest and learn from it)


Animals may also have effects including
poisoned - venom or poison is still working in its body (traits VENOMOUS and POISONOUS, see SPECIES.md), it loses HP every tick until the toxin runs out
           VENOMOUS: the bitten animal gets 0.25 HP/tick for 240 ticks; POISONOUS: the animal that bites it gets 0.25 HP/tick for 360 ticks
           an animal holds one toxin at a time, a fresh dose replaces the old one and restarts the timer (never stacks); toxin damage ignores armor and HARD SKIN
starving - nutrition is 0, it loses HP every tick until it eats
dehydrated - hydration is 0, it loses HP every tick until it drinks
tired - stamina is below 15% of max, it walks at nearly its slowest and cannot sprint

effects are worked out from the animal's current state, not stored, and an animal can have any number at once
every effect is shown in the inspector under 'Effects' (poisoned also shows the ticks of toxin left)
