Simulation section should have the title of the project, with a click to start button.

The background should be a low poly 2d terrain that will be generated and provided by another file.

The terrain will be a 2d dataset but will be rendered in 3d simply for styling purposes and to enhance the user experience

upon clicking anywhere on the screen, the user will be transferred from the landing section and transitioned to the opening section

Besides the difference in GUI, moving from the landing section to the opening section should just be slightly zooming in on the terrain

the opening section will have the title of the game in the top left, a "start simulation button", a settings button which leads to a separate settings section which will be developed in another chat, and a credits section which will display information about the creators of this project.

all of these sections should be displayed separately but the user should remain on the same url page throughout so there is no transition or reloading issues.

the inspiration for this page setup is modern video games with the same kind of simple page content changes while the background stays the same or is slightly different but the transition remains the same throughout.

once the terrain object is given, the entire GUI and background should be displayed with typescript, three js, and react

the terrain should be low poly aesthetic, 3d, colorful, almost cute. No animals will be generated yet, that will come at a later date. right now the only thing to worry about is the GUI and the background terrain for the simulation
